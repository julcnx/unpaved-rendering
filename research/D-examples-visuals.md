# D. Examples and visuals

## D2. Styling mockups

Model (decided 2026-11-02, see [C-statistics.md](C-statistics.md) decision 9): two levels, **Paved** and **Unpaved**, plus an optional **Off-road mark** drawn on top of **Unpaved roads only** when there is positive evidence (`smoothness`, `tracktype`, `4wd_only`). A paved road never gets the mark ("Paved + Off-road makes no sense"). A provider can ship the two levels first and add the mark later.

Generated by [mockups/make-mockups.ts](mockups/make-mockups.ts) (`node mockups/make-mockups.ts`, SVG), PNG made with headless Chrome at 2x. Yellow tertiary road in three states: Paved, Unpaved, Unpaved + Off-road. Colours are illustrative, close to common OSM styles.

| File | Unpaved | Off-road mark |
|---|---|---|
| [mockups/options-comparison.svg](mockups/options-comparison.svg) ([png](mockups/options-comparison.png)) | all three options | |
| [mockups/option-tint-dash.svg](mockups/option-tint-dash.svg) ([png](mockups/option-tint-dash.png)) | class colour shifted toward sandy | brown centre dash |
| [mockups/option-dots-dash.svg](mockups/option-dots-dash.svg) ([png](mockups/option-dots-dash.png)) | regular dots | brown centre dash |
| [mockups/option-dots-dense.svg](mockups/option-dots-dense.svg) ([png](mockups/option-dots-dense.png)) | regular dots | tighter dots |

Review (2026-11-02):

1. **Tint + dash is the clearest**: all three states differ, the tint reads as unpaved at a glance, the dash adds Off-road without hiding it. Recommended first option for providers.
2. Dots + dash: busy when both are on, dots and dash compete inside a narrow road.
3. Dots + dense dots: clean, one signal family, only the spacing changes. Works now that the mark is never on paved roads.

Design history: the first mockups (three levels Paved / Rough / Off-road, options texture, centre dash, tinted fill) were replaced when the model changed to two levels plus a mark. Earlier feedback kept: regular dots, not random speckles; one grain size, only spacing changes; light tint so the road still reads as its class colour, not as a brown track.

## D1b. Street-level imagery check (2026-11-02)

Satellite alone is not enough evidence, so each example needs Mapillary or Google Street View. [examples/imagery-check.ts](examples/imagery-check.ts) samples 8 points along each way and looks for the nearest image within 50 m, with the same lookups as `unpaved-app/app/js/street-view.js` (Mapillary Graph API, Google Street View metadata API). Keys are read from `unpaved-app` at run time, never stored here. Candidates: [examples/candidates.txt](examples/candidates.txt) (wiki and famous roads) plus the top 3 major roads classified Off-road per country from the stats. Full table: [examples/imagery.md](examples/imagery.md) (62 roads).
