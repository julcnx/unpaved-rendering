# Provider rules against ours

Generated by `stats/provider-gaps.ts` from `stats/combos/` (54 countries, Antarctica excluded, 20.0 million km). Each provider's paved/unpaved rule, copied from its source, is run on the same roads as ours ([classifier](../classifier/classify.ts): paved whitelist, missing surface = paved on roads). It shows the data side only: zoom limits and road classes without any styling are noted in the rule column.

- **Covers**: share of our Unpaved km that the provider also draws as unpaved.
- **Missed**: our Unpaved km it draws as paved, with the biggest values.
- **Extra**: km it draws as unpaved that we call Paved (tagged or untagged), with the biggest values.

## Rules

- **OSM Carto**: [functions.sql `carto_highway_int_surface`](https://github.com/openstreetmap-carto/openstreetmap-carto/blob/003cefdd/functions.sql#L77): explicit unpaved list, everything else paved
- **OpenMapTiles (Americana, MapTiler, Stadia)**: [Transportation.java L132-L139](https://github.com/openmaptiles/planetiler-openmaptiles/blob/5a837b161/src/main/java/org/openmaptiles/layers/Transportation.java#L132-L139): explicit unpaved list (`tracktype` only adds `grade1` as paved); from z12 only
- **CyclOSM**: [views.sql `surface_type`](https://github.com/cyclosm/cyclosm-cartocss-style/blob/7b446ca8/views.sql#L149-L172): `smoothness` > `tracktype` > `surface`, explicit lists; dashes on primary and below only, from z14
- **Organic Maps / CoMaps (data only, not drawn)**: [osm2type.cpp L579-L581, L700-L756](https://github.com/organicmaps/organicmaps/blob/3e4abc2c1b/generator/osm2type.cpp#L579-L581): paved whitelist; no surface but very bad `smoothness` = unpaved
- **HOT Humanitarian**: [project.yml L343-L351](https://github.com/hotosm/HDM-CartoCSS/blob/ff2bb32dc96e5e450dab052be0df0dff40f1c139/project.yml#L343-L351): 4-value paved whitelist; no surface is paved on main roads, unpaved on unclassified and residential
